# 帽子設計模組器（WAKNS Cap Configurator）

3D 帽子設計工具，純前端單一頁面（Three.js），不需要建置流程。

## 功能
- 6 種帽型：老帽、結構棒球帽、平簷 Snapback、卡車帽、五片帽、漁夫帽
- 文字／圖片 logo 模組：字型、顏色、大小、弧度、旋轉、立體刺繡／平面刺繡／印刷
- 25 個 logo 位置（正面、側邊、背面、帽簷、帽簷底面、帽頂）
- 設計師 PNG 素材庫（存在瀏覽器）
- 截圖輸出：只有帽子／正方形／目前畫面／四視角拼圖／自訂框選，透明背景、1–3x 解析度
- 設計存檔：本機快速存檔、下載／開啟 `.json` 設計檔（圖片一起打包）
- 工廠規格單

## 本機預覽
```bash
npx serve .
```

## 部署
Vercel 匯入此 repo，Framework 選 **Other**，不用設定 build 指令，直接部署即可。
